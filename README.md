# 📦 Suivi des Livraisons de Batteries - My Solar Battery

Application Streamlit permettant de :
- Scanner des photos de batteries via OCR / code-barres
- Enregistrer automatiquement les numéros dans un fichier Excel Dropbox
- Suivre les livraisons par fournisseur et date

## 🚀 Déploiement sur Streamlit Cloud
1. Connecter ce dépôt à Streamlit Cloud
2. Fichier principal : `app_streamlit.py`
3. Dépendances : `requirements.txt`
4. Ajouter le logo `logo.png` dans le même dossier
